# 界面语言

中文源文案直接作为词典键，`en.ts` 和 `ja.ts` 分别保存英语与日语译文。
组件通过 `useI18n()` 获取 `t`、`locale` 和 `setLocale`；界面语言保存在
`homura_locale`，未设置或值无效时使用简体中文。

动态句子使用完整文案和命名参数，避免按中文顺序拼接译文：

```ts
t('第 {0} 页', { 0: pageNumber });
```

只翻译应用提供的文案。书名、作者、正文、章节名、文件名、用户书库名以及
远程更新说明保持原文。静态选项在渲染时调用 `t(option.label)`，
或在 `computed` 中翻译，确保语言切换时即时更新。

新增文案时同步维护两份词典。缺少译文时回退中文，参数按文本插值，不执行
HTML 或 JavaScript。语言切换不重新挂载应用，不重置阅读位置或布局。
