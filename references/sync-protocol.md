# WebDAV 元数据同步协议

本文说明当前工作区中的 WebDAV 同步实现。同步默认关闭，用户在「设置 → WebDAV 同步」中主动启用后，才允许向指定服务器发送同步元数据。它不依赖 HOMURA 专用服务端；当前没有 S3 适配器或专用 Docker 服务端。

## 同步范围

| 数据 | 是否同步 | 说明 |
| --- | --- | --- |
| 阅读进度 | 是 | 页索引、总页数、整体比例、章节索引、章节内比例及更新时间 |
| 收藏 | 是 | 每本作品的收藏 / 取消收藏状态 |
| 书库 | 是 | 稳定 ID、名称、创建时间及作品归属 |
| 原文件、正文、图片和封面 | 不上传 | 可自行导入本机；也可只读浏览 WebDAV 目录并在线阅读 |
| 设备排版与偏好 | 否 | 字号、字体、行距、页边距、方向、单双页、主题等仍由本机保存 |
| 本机路径与文件句柄 | 否 | 不进入远端文档 |

书库名称、内容指纹、进度和收藏状态会出现在服务器上的 JSON 文档中。HTTPS 保护传输，当前没有对同步文档做端到端加密。

## 配置与使用

1. 在 WebDAV 服务器上预先创建一个目录，确认账号拥有读取和写入权限。
2. 在各设备导入相同原文件，打开「设置 → WebDAV 同步」，填写该目录的 HTTPS 地址、用户名及密码或应用专用密码。地址不能包含账号、密码、查询参数或片段，应填写最终地址，不能依赖重定向。
3. 保存设置后可点「测试连接」。测试仅执行读取；远端文件不存在时也可通过，写入权限及服务器条件写入行为要在实际同步时验证。
4. 主动开启「启用 WebDAV 同步」并保存，然后点「立即同步」。如果同时开启「自动同步」，保存后应用就可自动发起同步；若希望先测试再发送数据，可先保持同步关闭。
5. 有认证的连接在应用重启后需重新填写并保存本次会话密码。密码不会被应用写入浏览器持久存储或同步数据库。

连接地址、用户名、启用状态和自动同步偏好保存在本机浏览器持久存储中。移除此设备的连接会清除连接配置和会话凭据，不删除本机作品或服务器文档。原有同步工作状态仍保留在本机独立数据库中。

自动同步依赖应用运行且网络可用。应用会观察本机元数据更改，并在恢复联网、窗口获得焦点或重新可见等时机尝试同步；它不是 Android 后台常驻服务。

## 内容身份与匹配

普通文件按原始字节计算 SHA-256，身份格式为 `sha256:` 加 64 位小写十六进制摘要。本机书籍 ID、文件名、导入时间不参与匹配。因此，同一文件改名后仍可匹配；内容相近但字节不同的 EPUB 版本、重新打包的压缩包不会自动归为同一本书。

图片文件夹先为每个文件计算摘要，再将 `[相对路径, 文件摘要]` 按相对路径排序，以其 JSON 的 UTF-8 字节计算整体 SHA-256。顶层文件夹改名不影响身份，内部相对路径或文件内容变化会改变身份；重复路径及越界路径会被拒绝。

浏览器按块读取文件计算摘要，Tauri 可用原生命令流式计算应用私有源文件的摘要。暂时不可读取的源文件保持待识别，其他作品仍可同步，后续再重试。

内容指纹会在本机缓存。桌面外部文件句柄每次通过同一份 `File` 快照检查大小与修改时间，属性变化时重新计算摘要；保留大小和修改时间的等长外部改写无法仅靠这一检查发现。AppData、OPFS 与 Blob 副本按应用管理的不可变来源复用缓存。

只有在本机存在匹配作品时，远端进度、收藏和归属才会应用到该作品。仅远端存在的作品记录会保留，不会生成没有原文件的本机书籍。首次导入产生的默认未收藏、空进度和未归属状态不会直接抹掉已有远端记录。

## 文档与逻辑版本

一个目录使用一个固定文件：`homura-sync-v1.json`。它是 UTF-8 JSON，顶层结构为：

```json
{
  "schemaVersion": 1,
  "records": [
    {
      "kind": "favorite",
      "key": "sha256:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
      "version": { "counter": 7, "deviceId": "device_A" },
      "value": true
    }
  ]
}
```

每条记录由 `kind:key` 唯一定位，分别保存下列逻辑字段：

| `kind` | `key` | `value` |
| --- | --- | --- |
| `progress` | 作品内容指纹 | 便携阅读进度对象 |
| `favorite` | 作品内容指纹 | `true` 或 `false` |
| `collection` | 稳定书库 ID | `{ title, createdAt }` |
| `membership` | 作品内容指纹 | 一个书库 ID，或表示移出的 `null` |

每次已观察到的本地字段更改都会推进逻辑计数器。合并同一条记录时，先比较 `counter`，相同则按 `deviceId` 字典序决胜；设备时钟和阅读比例不决定覆盖顺序。`progress` 对象作为一条记录合并，不逐个比较它内部的页码字段，也不自动选择读得更远的一方。

删除书库、清空进度等使用 `deleted: true, value: null` 的墓碑记录，参与相同的版本比较；取消收藏用 `false`，移出书库用 `null`。相同版本出现不同值时使用确定性规则，墓碑优先，保证合并收敛。当前不会自动清理墓碑；不要手工删除记录来表示删除，否则离线设备保留的旧记录可能重新出现。

作品归属单独记录，最多指向一个书库，维持本机「每本作品最多属于一个书库」的约束。删除书库不删除书籍原文件。单独移除本机书籍也不会要求其他设备删除原文件。

进度只包含位置数据，导出和应用时均保留设备自己的排版设置。不同屏幕和排版可能改变分页，因此页码不保证逐页一致；当前没有跨版本正文锚点。同步不会把正在打开的作品强制跳到远端位置。

## 网络与并发

同步按「读取远端 → 观察本地更改 → 合并 → 应用本机元数据 → 条件写入远端」进行。本地应用和远端提交不是跨设备事务；远端写入失败时会显示错误，保留本地同步状态供重试。

- 元数据同步仅对固定文件执行 `GET` / `PUT`，不执行 `MKCOL` 或删除远端文档。下述远程阅读独立使用只读目录与 Range 请求。
- `GET` 返回 `404` 表示首次同步。创建时使用 `If-None-Match: *`，防止覆盖另一设备刚创建的文件。
- 已有文件必须返回带双引号的强 `ETag`。弱 ETag（`W/`）或缺失 ETag 都会停止同步，不能降级为无条件覆盖。
- 更新使用 `If-Match: <ETag>`。服务器返回 `409` / `412` 时重新读取、合并并有限重试；持续冲突会报告失败。
- 同步期间出现本地编辑时会重新读取并核对本机快照；同步工作状态也以本地修订号防止并发写入相互覆盖。浏览器支持时还会使用 `navigator.locks` 协调同源页面。
- 同步文档上限为 8 MiB、50,000 条记录；严格验证协议版本、字段、类型和数值范围，超限或无效文档会停止同步。单次网络请求超时为 30 秒。

服务器必须正确实现强 ETag 和条件写入语义。只有文件存储 API、忽略 `If-Match` 的反向代理或直接使用 S3 URL，不能视为已兼容此协议。

## HTTPS、浏览器 CORS 与原生请求

生产连接必须使用 HTTPS。仅 `localhost`、`127.0.0.1` 和 `[::1]` 允许 HTTP，供本机开发测试。认证使用用户名 / 密码构造 Basic Authorization，不把凭据嵌入 URL，不携带浏览器 Cookie。

浏览器版走 `fetch`，服务器及反向代理需要按实际应用来源配置 CORS：

- 允许该来源执行 `GET`、`PUT`，并处理 `OPTIONS` 预检。
- 允许请求头 `Authorization`、`Content-Type`、`If-Match`、`If-None-Match`。
- 使用 `Access-Control-Expose-Headers: ETag` 暴露响应 ETag；仅允许请求 ETag 并不足以让浏览器读取它。
- 让鉴权、错误响应及首次文件不存在的响应也保留所需跨域头。

Tauri 应用使用 Rust 原生 HTTP 命令，不受浏览器 CORS 约束；原生请求失败后不会静默回退浏览器。此通道仍执行相同的 HTTPS、固定文件、限额和条件写入限制，也不需要放开整个 WebView 的 CSP 网络白名单。

## 本机存储与验证边界

书架、原文件与进度仍以原有 `homura_shelf` IndexedDB 为本机依据，原生 SQLite 保持元数据镜像职责。同步文档、比较基线、指纹及修订号保存在独立的 `homura_sync` IndexedDB，按规范化目录地址和用户名区分连接。同步应用元数据时保留设备排版，并遵守原有 SQLite dirty 标记与重建顺序。

当前已有内容指纹、模型校验、合并、离线更改、冲突重试与 WebDAV 传输等自动化用例，以及浏览器界面检查；这些检查不等于真实服务器兼容性认证。**真实 NAS / WebDAV 服务部署及 Android 设备上的完整同步链路仍未实测**，包括证书、反向代理、网络切换、系统挂起和多设备长期运行。上线使用前需在目标环境验证读取、首次创建、条件更新及并发冲突行为。

## 远程目录与在线阅读

「设置 → WebDAV 同步 → 远程书籍」复用已保存的目录、用户名与当前会话密码。仅浏览和阅读不要求启用元数据同步，也不要求服务器提供写权限。支持进入子目录、返回上一级和刷新；目录通过 WebDAV `PROPFIND`（`Depth: 1`）读取，只显示支持的书籍和文件夹。

- EPUB、CBZ、ZIP：先用 HTTP Range 读取 ZIP 中央目录，再读取正文、封面或当前页面所需的条目。兼容单卷 ZIP64、Store / Deflate，拒绝加密包、越界路径、超限目录和条目。EPUB 小说沿用现有分页，需要加载章节正文与排版所需的插图；漫画图片按页读取。
- PDF：pdf.js 使用自定义 Range 传输，关闭自动预取和连续下载，页面仍使用现有按页渲染与 24 页位图缓存。
- TXT / Markdown：正文完整载入内存进行分页，上限 8 MiB，不保存原文件。MOBI / PRC / AZW 暂不支持在线阅读。

直接在线阅读创建临时会话；也可点「添加到书架」，在 `books` / `sources` 保存轻量书目、封面缩略图和云端引用，并在书本封面显示「云端」标签。两种方式都不写 AppData / OPFS / IndexedDB 原文件副本。阅读所需的字节和页面位图会进入内存，因此「无需下载」指无需先下载整本并存档，并非没有网络传输。云端引用不包含密码，重启后根据当前 WebDAV 设置与会话密码重新连接；连接不匹配或未填写密码时会提示到设置处理。移除云端书只移除本机引用，不会删除服务器文件。进度与排版使用连接目录、用户名和远端地址的稳定摘要在本机记忆；它们不参与基于原文件内容指纹的跨设备元数据匹配。关闭阅读器后清理会话及页面资源，重新打开需要网络和有效会话密码。

服务器须支持 `206 Partial Content` 与正确的 `Content-Range`；忽略 Range 返回 `200` 时立即停止，不回退整本下载。每次读取上限 8 MiB、30 秒超时；ZIP 条目压缩后上限 64 MiB，图片解压后上限 256 MiB，单个文本条目上限 8 MiB，中央目录上限 16 MiB / 20,000 条。提供强 ETag 时用 `If-Match` 固定版本，否则在提供有效 Last-Modified 时使用 `If-Unmodified-Since`；缺少二者时只能核对范围与总长度，无法检测保持文件长度不变的远端改写。

浏览器服务端还须允许 `PROPFIND`、`Depth`、`Range`、`If-Unmodified-Since`，并暴露 `Content-Range`、`ETag`、`Last-Modified`、`Content-Length`。Tauri 通过新增只读原生命令访问，不放宽 WebView CSP。原生命令仍限制为同源配置目录内的 URL，禁止重定向、编码分隔符、双重编码和路径穿越。

验证使用自动化用例和本机模拟 WebDAV；真实 NAS、真实大书和 Android 设备在线阅读仍需分别验证。
